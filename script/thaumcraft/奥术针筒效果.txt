==============================================================================
整理日期：2026-09-16
对象模组：Thaumic Horizons / 神秘视界  thaumichorizons-1.21.1-0.1.0-scex-dev.34.jar
（位于 libs/implementation/，也存在于整合包 mods 目录）
代码来源：反编译该 jar 的 com.kentington.thaumichorizons.common.blood.* 类，
          再用 javap -c 读常量池，所以下面的权重数字都是字节码里的原始值。
  BloodWeights.create()      -> 要素 -> (效果键, 权重) 的 TABLE
  BloodFormula.calculate()   -> TABLE 如何折算成实际药水效果
  BloodEffects.resolve()     -> 效果键 -> 真实药水效果（含模组自注册效果）
  InjectionItem              -> 注射剂怎么用、效果怎么施加
  BloodInfuserBlockEntity    -> 血清转化仪怎么吸源质、怎么产出

【结论先说】
1. 奥术针筒本身不能装源质，它只是抽血工具。源质是加在"血清转化仪（Seroconverter）"
   里的，和"含血奥术针筒"一起作用，产物叫"注射剂（Injection）"。
   所以"不同源质产生什么效果"真正的规则是注射剂配方规则。
2. 最多放 8 点源质（可以是多种要素混搭），最终生效的效果个数 = (总点数+1)/2，最多 4 个：
   也就是"每 2 点源质换 1 个效果"，这是硬规则，负效果也会占名额。
3. 每个要素对多种药水效果各有一个"亲和权重"，把所有点数的贡献加起来，取分数最高的前几名。
4. 分数还决定强度：等级 = 分数/30，持续时间 = 分数 x 100 tick（分数 x 5 秒）。
5. 一共有 48 个要素可以注射，完整权重表见第四节。

二、完整流程
------------------------------------------------------------------------------
1) 手持奥术针筒右击（对着空气或自己）-> 变成"含血奥术针筒"，即抽出自己的血。
   对着其它可取样生物右击 -> 得到"血之样品"，不是含血针筒。
   可取样条件（BloodSampleItem.canSample）：是 Mob、存活、不带 UNDEAD 标签、
   不是 NPC/商人，且生物分类为 CREATURE/AMBIENT/水生一类（MONSTER 怪物类不能取样）。
2) 把含血奥术针筒（或爆裂安瓿）放进血清转化仪的输入槽，在界面里点选要素与数量，
   总点数 <= 8；界面只允许选第四节表里的 48 个要素。
3) 用要素管道/要素罐给机器输入源质。机器实现了 IEssentiaTransport + IAspectContainer，
   会按所选要素一点一点地吸（每次 1 点，六面除上方外都能吸），吸满所选数量后才产出。
4) 产出注射剂进入输出槽（槽 1~9）：
   - 自己右击使用（按住 8 tick 的弓动画）-> 效果作用到自己；
   - 直接左键打别的生物 -> 效果作用到目标；
   - 放进针筒发射器当弩箭发射。
   若输入的是爆裂安瓿，产出的注射剂会带 PHIAL 组件，变成可投掷的爆裂安瓿。

机器模式（GUI 切换，setMode 只接受 0~2）：
  mode 1 = 单次：产出 1 份后自动停机（mode 变回 0）。
  mode 2 = 自动：只要有含血针筒、源质够、还有空输出槽，就持续产出。
  mode 0 = 关闭。


三、效果是怎么算出来的（BloodFormula.calculate 逐步还原）
------------------------------------------------------------------------------
输入：Map<要素, 数量>；每个要素数量 1..8，且总和 <= 8（MAX_SELECTION = 8）。
不在权重表里的要素会被拒绝（抛 "has no blood infusion data"），所以做不出效果。

第 1 步  累计亲和分数：
    score[效果] = Σ ( 要素使用点数 x 该要素对该效果的权重 )
    例：Lux 对 night 的权重是 8、对 blind 是 2。用 2 点 Lux -> night=16, blind=4。

第 2 步  决定生效几个效果：
    个数 = min( (总点数 + 1) / 2 , 候选效果种类数 )
    1~2 点 -> 1 个；3~4 点 -> 2 个；5~6 点 -> 3 个；7~8 点 -> 4 个（上限 4）。
    注意"候选效果种类数"也会卡上限：只用 1 种要素（如只用灵气）时最多只有它带的几种效果。

第 3 步  排序取前 N 名：
    先按 score 从大到小；score 相同时按效果键的字母序（代码是 comparingInt(value).reversed()
    再 thenComparing(key)），所以并列时会优先取 fatigue、blind 这类字母靠前的键。

第 4 步  每个效果折算数值：
    等级 amplifier = score / 30   （整数除法；amp 0 即游戏里的 I 级，1 即 II 级）
    持续时间 = score x 100 tick = score x 5 秒
    例外：瞬间治疗(health) / 瞬间伤害(harm) 的持续时间固定写成 1 tick，
          因为它们是瞬间效果，真正起作用的是等级；
          施加时走 MobEffect.applyInstantenousEffect(..., amplifier, 1.0)。

第 5 步  颜色：注射剂颜色 = 各要素自身颜色的加权平均（按点数加权），只影响外观。

验证（模组自带研究文本的例子与代码完全一致）：
  * 2 点 Lux：night = 2x8 = 16 -> 个数 (2+1)/2 = 1 -> 夜视 I 级，1600 tick = 80 秒。
  * 3 点 Lux：night = 24、blind = 6 -> 个数 2 -> 夜视 I 级 120 秒 + 失明 I 级 30 秒。
  * 3 点 Lux + 1 点 Perfodio（= Aspect.MINE 矿藏）：night=24、blind=6、haste=1x10=10
    -> 个数 (4+1)/2 = 2 -> 取前 2 名 = 夜视(24) + 急迫(10)，失明被挤掉。
    （这正是研究文本里"第四点用 Perfodio 就变成夜视+急迫"的说法。）

六、模组新增 / 借用的 6 个特殊效果的实际效果（BloodEffects$InfusionEffect）
------------------------------------------------------------------------------
这些不是原版药水效果，光看名字不知道干什么，所以单独说明（等级 = amplifier）：

1) visRegen 灵气创生（thaumichorizons:vis_regen，本模组注册，正面效果）
   每隔 max(1, 20 - 3x等级) tick，在自己脚下生成 1 个随机元始要素的要素球
   （AspectOrbEntity，从 6 个元始要素 Aer/Terra/Ignis/Aqua/Ordo/Perditio 里随机挑 1 个），
   等于持续产出源质。等级 0 时约每秒 1 个；灵气 8 点（等级 II）时约每 0.7 秒 1 个。
2) vacuum 物件真空（thaumichorizons:vacuum，本模组注册）
   每 tick 把周围 min(64, 10 + 2x等级) 格内的掉落物往自己身上拉
   （每 tick 减去 0.1 的归一化速度，单轴变化上限 ±0.35），并生成附魔粒子。
   等级 0 时半径 10 格，等级 II 时 14 格。
3) shock 静电震击（thaumichorizons:shock，本模组注册）
   每 tick 对 10 格内的其它存活生物，按 (20 x (1+等级)) / 1000 的概率造成 1 点伤害
   （伤害来源是自己时算玩家攻击，否则算魔法伤害），并播放闪电链特效与 zap 音效。
   等级 0 = 每个目标每 tick 2% 概率，等级 II = 6%（平均每秒约 1.2 点伤害/目标）。
4) synth 光合作用（thaumichorizons:synthesis，本模组注册）
   每隔 max(1, 15 - 2x等级) tick，若是白天且头顶能看到天空：治疗 0.5 点生命；
   如果是玩家，额外恢复 1 点饥饿值与 0.5 饱和度。等级 II 时间隔 11 tick，约每秒 0.9 点生命。
5) taint 腐毒（借用神秘时代 thaumcraft:flux_taint）
6) visBoost -> 实际是 咒流（借用神秘时代 thaumcraft:vis_exhaustion）
   ！注意：权重表里的键是 "visBoost"，但 BloodEffects.resolve() 把 "visBoost" 映射到了
   神秘时代的"咒流（Vis Exhaustion）"，而模组自己注册的"灵气增幅"（effect.thaumichorizons.vis_boost）
   在 resolve() 里根本取不到（没有任何分支返回 VIS_BOOST）。
   所以：异域/魔力/污染/思维/灵魂带 visBoost 的要素，实际给的是咒流而不是灵气增幅。
   这属于上游遗留 / 疑似 bug，用之前自己确认一下。

八、注意事项 / 坑
------------------------------------------------------------------------------
* 奥术针筒本身不存源质，别想把源质灌进针筒；针筒里只能装血。
* 血清转化仪的输入槽必须是自己抽出来的"含血奥术针筒"（或爆裂安瓿）；
  "血之样品"（动物血）只能拿去做复制/治愈之缸，不能做注射剂，
  对应研究文本里"动物血不适合炼金处理"的说法。
* 总点数上限 8、效果上限 4、"每 2 点换 1 个效果"是硬规则；
  3 点以上一定会出现第二个效果（哪怕是负面效果），所以别乱混要素。
* 同一个要素往往正负效果混杂（Lux 有夜视也有失明；Fames 有饱和也有饥饿；
  Gelum 五种全是负面），控制手段就是"用别的要素的高分效果把负面效果挤出前 N 名"。
* 效果键并列时按字母序取，不是按"你觉得哪个更好"，所以算的时候要按第 3 步的规则。
* 要素名对照：研究文本里的旧式名字 Perfodio = Aspect.MINE（矿藏/挖掘），
  Lux = LIGHT（光明），Aer/Terra/Ignis/Aqua/Ordo/Perditio = AIR/EARTH/FIRE/WATER/ORDER/ENTROPY。
* 权重表之外的要素（例：磁力 magnetis、轨迹 orbita、容器 vas 等）选不了，也做不出注射剂。
* 注射剂是一次性消耗品：finishUsingItem / hurtEnemy 后 count-1（创造模式不消耗），
  手上只有 1 个时用完那一格就空了。
* 爆裂安瓿用的是同一套公式和权重表，只是产物带 PHIAL 组件，变成可投掷版本。
* 血清转化仪是"先吸满所选要素再产出"，中间没有进度损失；
  单次模式在产出 1 份后会自动停机（mode 归 0），批量生产请用自动模式。
