🧱 方块 · 底层逻辑树 MC Java Edition

从 JVM 内存对象到玩法交互 —— 每一层都展开了代码级的子结构，点击任意节点可折叠/展开
  • 🎮 玩法层（玩家可感知） 顶层
    • 交互 onUse / onBreak / onSteppedOn
      • onUse InteractionResult use(BlockState, Level, BlockPos, Player, InteractionHand, BlockHitResult)
        • 触发条件：右键点击方块
        • 返回值：SUCCESS / CONSUME / PASS
        • 典型：箱子打开、按钮按下、门旋转
      • onBreak void onRemove(BlockState, Level, BlockPos, BlockState newState, boolean isMoving)
        • 掉落处理：getDroppedStacks
        • 统计：玩家统计信息触发
      • onSteppedOn void stepOn(Level, BlockPos, BlockState, Entity)
        • 典型：岩浆伤害、耕地踩踏、压力板激活
    • 掉落 getDroppedStacks
      • 工具条件：requiresCorrectToolForDrops
      • 精准采集：hasSilkTouch
      • 时运附魔：BonusLevelDropProvider
      • 战利品表：LootTable 随机池
    • 音效 SoundType
      • 破坏音：breakSound
      • 放置音：placeSound
      • 踩踏音：stepSound
      • 材质映射：木头/石头/金属/草/沙…
    • 红石导体
      • 是否传导：isRedstoneConductor
      • 弱充能/强充能判定
      • 影响：箱子开合、红石灯亮灭
    • 窒息 & 视野阻挡
      • 窒息：isSuffocating
      • 视野：isViewBlocking
      • 光照遮挡：canOcclude / getLightBlock
  • ⏱️ 刻层（随时间变化）
    • randomTick（随机刻） 每 Section 每刻随机 3 方块
      • 调用：randomTick(BlockState, ServerLevel, BlockPos, RandomSource)
      • 典型行为：作物生长、冰融化、铜氧化、草蔓延
      • 触发条件：isRandomlyTicking() 为 true
    • tick（计划刻） 精确延迟
      • 调用：tick(BlockState, ServerLevel, BlockPos, RandomSource)
      • 调度：scheduleTick / LevelTicks
      • 典型：液体流动、红石中继器延迟、门自动关闭
      • 数据结构：LevelTicks 按优先级队列
    • BlockEntity.tick 每游戏刻
      • 调用：BlockEntityTicker<T> ticker
      • 典型：熔炉燃烧、漏斗传输、信标效果、刷怪笼
      • 条件：getTicker() 返回非 null
      • 注意：仅在区块加载时执行
  • ⚙️ 行为层 BlockBehaviour
    • Properties（静态规则）
      • 物理属性
        • friction 摩擦力 (默认 0.6)
        • speedFactor 速度乘数
        • jumpFactor 跳跃乘数
      • 挖掘属性
        • destroyTime 硬度
        • explosionResistance 爆炸抗性
        • requiresCorrectToolForDrops 工具需求
      • 交互属性
        • hasCollision 碰撞
        • canOcclude 遮挡
        • replaceable 可替代（草/雪）
        • isAir / isLiquid 特殊标记
      • 渲染属性
        • renderShape (MODEL/INVISIBLE/ENTITYBLOCK)
        • noOcclusion 不遮挡
        • lightLevel 发光等级
    • neighborChanged（邻居更新）
      • 调用：neighborChanged(BlockState, Level, BlockPos, Block, BlockPos, boolean)
      • 触发：红石信号变化、方块放置/破坏
      • 典型：红石灯亮灭、铁轨更新、活塞响应
    • BlockEntity（动态数据容器）
      • 持久化：saveAdditional / loadAdditional
      • 网络同步：getUpdateTag / getUpdatePacket
      • 数据槽：Container (箱子/熔炉)
      • 渲染接口：BlockEntityRenderer
    • 形状与碰撞
      • getShape / getCollisionShape
      • getVisualShape 视觉形状
      • isFaceSturdy 面坚固度
  • 🧩 状态层 BlockState（不可变）
    • Property<T>（属性）
      • facing (Direction) 朝向
      • powered (Boolean) 充能
      • waterlogged (Boolean) 含水
      • age (Integer) 生长阶段
      • half (Enum) 上下半砖
      • shape (Enum) 楼梯/铁轨形状
      • 自定义属性：BooleanProperty / EnumProperty / IntegerProperty
    • 组合生成
      • 笛卡尔积：所有属性值组合
      • 启动时：BlockStateDefinition 生成全部合法状态
      • 不可变性：状态一旦创建永不改变，setValue 返回新实例
      • 缓存：BlockState 实例全局唯一
    • Block 实例无状态
      • 所有石头共享同一个 Block 对象
      • 状态查询：defaultBlockState()
      • 注册表：BLOCK_STATE_REGISTRY
    • 状态切换
      • setValue(Property, T)
      • cycle(Property) 循环切换
      • getValue(Property)
  • 🆔 注册与 ID 层
    • BLOCK_STATE_REGISTRY
      • 映射：BlockState ↔ 整数 ID
      • 用途：网络传输、存档存储
      • 上限：24 位 ID (16,777,216)
      • 全局静态：Block.BLOCK_STATE_REGISTRY
    • Block 继承链
      • Block extends BlockBehaviour
      • 实现 ItemLike 接口（关联物品）
      • NeoForge：IBlockExtension 注入模组能力
      • Fabric：FabricBlockSettings 扩展
    • 注册流程
      • Registry.register(BuiltInRegistries.BLOCK, ...)
      • 方块物品：BlockItem 自动注册
      • 数据包：BlockState 模型映射
  • 💾 存储层（内存/磁盘）
    • Chunk Column
      • 高度：LevelHeightAccessor (1.18+ 可变高度)
      • Section 划分：16×16×16
      • Section 数量：getSectionsCount()
    • PalettedContainer<BlockState, 4096> 调色板压缩
      • 位宽：1~8 bits（根据种类数量动态）
      • 调色板：Palette<BlockState>
      • 单值优化：全部相同方块 → 只存一个 ID
      • 全局调色板：超过 256 种时回退到直接存储
      • 存储数组：long[] 打包数据
    • 索引顺序
      • Y × 256 + Z × 16 + X (Y-major)
      • 原因：光照传播沿 Y 轴迭代，缓存友好
      • 局部坐标：0~15 每轴
    • 磁盘序列化
      • 区块格式：ChunkSerializer
      • 压缩：RegionFile 分区存储
      • 版本迁移：DataFixerUpper
  • 🎨 渲染层
    • 静态模型
      • BakedModel / BlockStateModel
      • 模型加载：ModelBakery
      • JSON 模型：assets/<namespace>/models/block/
      • 方块状态映射：blockstates/ JSON
    • 动态渲染 BlockEntityRenderer
      • 提交/渲染分离：
        • createRenderState 创建状态对象
        • extractRenderState 提取动态数据
        • submit 提交到渲染队列
      • 变换矩阵：PoseStack.translate(0.5, 1.0, 0.5)
      • 典型：箱子、告示牌、旗帜、床
    • 批量绘制 MultiDrawIndirect 新快照
      • 打包多个绘制调用 → 单次 GPU 提交
      • 减少 CPU 开销，复杂场景性能提升
      • 适用：大量区块加载、密集方块
    • 渲染层（RenderType）
      • solid / cutout / cutout_mipped / translucent
      • 决定透明度、剔除、排序
    • 光照与 AO
      • 平滑光照：AmbientOcclusion
      • 亮度缓存：LightEngine
      • 方块发光：getLightEmission
