**合成结果导入卡**是一种专用于**样板供应器**的升级组件，它能够简化自动化加工流程，免除为机器单独安装导入总线的需求（尤其适用于原版熔炉等无法自动输出物品的机器）。

安装该卡后，**样板供应器本身**即可从相邻机器中拉取加工完成的物品，从而将“输入材料”和“回收产物”两项功能整合到同一个方块中。

模组为**样板供应器**新增了一个升级槽位，可用于安装此卡片。

# 配置

手持该卡片并右键点击，即可打开配置界面：

* **仅导入合成结果：**
    * **启用（默认）：** 卡片会以“智能模式”运行。它会记录送入机器的原料，并计算预期产物，仅导入这些对应的结果物品，忽略机器中的其他物品。
    * **禁用：** 卡片将像普通输入总线一样工作，持续尝试将目标机器中的任意物品导入 ME 网络。
    * 启用该选项对性能更加友好，因为无需持续扫描机器库存。

* **与合成 CPU 同步：**
    * **启用（默认）：** 卡片会与负责当前任务的合成 CPU 通信。如果你在终端中取消了自动合成任务，卡片也会停止等待对应产物。
    * 这样可以避免样板供应器卡在等待一个永远不会产生结果的任务上。

* **导入方向：**
    * **自动：** 从与样板供应器接触的那一侧读取机器输出。
    * **指定方向（上、下、北等）：** 强制从相邻机器的指定面拉取物品。适用于仅能从特定方向输出的机器（例如侧面熔炉等）。

该卡片采用“指数退避（Exponential Backoff）”机制。当目标机器处理速度较慢时，检查频率会自动降低，以减少服务器负载；当新的加工任务开始时，则会立即恢复检测。

### 限制

* **仅适用于样板供应器：**
  该卡既支持完整方块版样板供应器，也支持面板/部件形式的样板供应器。不过对于完整方块版本，样板供应器必须明确指定朝向目标机器的某个面（可使用扳手进行调整）。
